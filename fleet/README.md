# VisionIST fleet

Generated by `tools/make_fleet.py` from the
[VisionIST_Library](https://github.com/sipg-isr/VisionIST_Library) registry,
pulling from **ghcr**, with GPU reservations.

```bash
docker compose pull      # no building: these are published images
docker compose up -d
docker compose ps
```

| Box | Config key | Runtime | Host port | What it does |
|---|---|---|---|---|
| `clip` | `clip` | gpu | 9061 | CLIP image and text embeddings with their cross-modal similarity |
| `features` | `features` | cpu | 9062 | SIFT keypoints in the SIFT-Extractor layout: (2+128) x N, annotated JPEGs, MATLAB .mat |
| `lang_sam` | `lang_sam` | gpu | 9063 | Text-guided segmentation with LangSAM: phrases in, masks out |
| `lightglue` | `lightglue` | gpu-or-cpu | 9064 | SuperPoint/DISK features and LightGlue matching, pairwise or as a sliding-window stream |
| `moge` | `moge` | cuda-only | 9065 | MoGe-3 monocular geometry: metric depth, point map, normals, intrinsics |
| `opencv` | `opencv` | gpu-or-cpu | 9066 | Classic feature extraction and matching: SIFT/ORB via FLANN, or SuperPoint/DISK via LightGlue, plus a RANSAC fundamental matrix |
| `sbert` | `sbert` | gpu-or-cpu | 9067 | Sentence-BERT text embeddings and their pairwise similarity |
| `tapnext` | `tapnext` | gpu | 9068 | TAPNext point tracking with the Tomasi-Kanade observation matrix |
| `unimatch` | `unimatch` | gpu-or-cpu | 9069 | Unified dense matching: optical flow, stereo disparity, and multi-view depth |
| `vggt` | `vggt` | gpu | 9070 | VGGT multi-view 3D reconstruction: world points, per-view depth, camera poses, and a GLB |
| `yolo` | `yolo` | gpu-or-cpu | 9071 | YOLO object detection with always-on tracking, on images or video |

Call one with the client:

```python
from visionist_client import Visionist
b = Visionist("localhost:9061")
```

To change the selection, re-run the generator rather than editing
`docker-compose.yml` - it is overwritten.
